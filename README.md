# HelloWorldAgents

> ⚠️ **This is not production code.** This repo is for personal learning and exploration only.

This project follows along with the Microsoft .NET blog post:
[Introducing Microsoft Agent Framework Preview](https://devblogs.microsoft.com/dotnet/introducing-microsoft-agent-framework-preview/)

It demonstrates a simple agent built with `Microsoft.Agents.AI` that uses GitHub Models to generate a short story.
